28.12 Common mistakes and gotchas

Mistakes that cost the most time
  • Masking a database you cannot restore. In-place jobs overwrite data. Cancelling a running job leaves semi-masked data, the docs warn. Snapshot first.
  • Believing SUCCEEDED means "all masked". Non-conformant values are skipped by default. Read the Execution Summary line for non-conforming data every time.
  • Leaving every profiler assignment in place when you only meant to mask one column. A job masks every assigned column in its rule set.
  • Letting the profiler overwrite your choice. Untick Enable Automatic Updates before assigning by hand.
  • Masking a key. Primary and foreign key columns need the same deterministic treatment everywhere, or none. In these labs, none.
  • Trusting the format file without checking the data. A wrong field count or length in a file format silently drops or shifts data.
  • Using a non-unique algorithm where uniqueness matters. The Name and lookup-style algorithms can collide; the Character Mapping family is the documented unique-output option.
  • Editing a shared file format. The inventory of a file belongs to its format, so changes touch every file that uses it.
  • Skipping the "before" snapshot. Without it you can show only that data is different, not that the right data is different.

28.13 Recap

Recap
  • The five labs form a chain: connector, rule set and profile, files, FirstName, then text, SSN and phone. Each depends on the previous one's output.
  • A "connector to a VDB" is an ordinary database connector pointed at a VDB. The VDB is the safe, disposable place to mask.
  • Profiling proposes domains and algorithms; the inventory is where you decide. Turn off automatic updates before overriding.
  • Files need a format file that describes their fields. Delimited formats list names; fixed-width formats list names and lengths. Mismatches silently drop or shift data.
  • A masking job masks every assigned column in its rule set, so keep rule sets purposeful, and verify with before/after queries, not with the job status alone.
  • Character Mapping algorithms (CM Digits, CM Alpha-Numeric) preserve format and give unique text outputs; Phone US gives fake but plausible numbers; FirstName is realistic but not unique.
  • Non-conformant data produces warnings and leaves values unmasked by default. Explain every warning before sign-off.
  • Evidence is what you hand to a reviewer: screenshots, query results, exported inventory, job reports, and a short list of which choices came from docs and which were yours.
