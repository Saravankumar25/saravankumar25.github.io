11.5 Helpers on every screen

Search, filters, Quick Links and preferences

  • Search field. Finds projects, plans, assignments, data sets and data set tables in the TDM and test data warehouse repositories. It cannot find connections. Results include the object plus what it contains and what contains it (p.39).
  • Advanced text filter. In column filters (Discover > Columns, Define > Data Masking, Define > Data Generation, profile results) type "FIRST_NAME" in quotes for an exact match, ORDER* for starts with, *_ID for ends with, or plain PHONE for contains (p.39).
  • Data filter. Type part of a name (the guide uses "Emp") in a column filter and click the Filter icon; click Reset Filter to clear it (p.40).
  • Quick Links. Shortcuts to create a rule, policy, data domain or project; what you see depends on your permissions (p.40).
  • User Preferences. The General tab has Show Start Screen; the Projects tab chooses which projects the Overview dashboards show (p.40).
  • Actions menu. Changes with the view; most tasks below start there (p.40).

11.6 The Overview view

Overview is a read-only "management view" of summary dashboards (User Guide 10.5.10, pp.41-42). The main ones: Project Risk Analysis (percentage of columns at each domain sensitivity level and the percentage in no domain), Project Assignments and Project Objects (counts for the last 10 projects), Recent Activities (the last 10 changes, with an Audit Trail report you can download), Plan Execution (plans in progress or completed on a date), Global Components (share of policies, rules and domains) and Recent Projects (the last 10 projects you modified). A sensitive-data distribution graph appears only if sensitivity levels are set.

Visual reference Informatica TDM 10.5.10 User Guide, p.41, Figure "Overview view". What to look for: a plan-execution timeline, a Global Components pie chart and a Recent Projects table.

11.7 Data Sets, Monitor, Parameters and Administrator

The Policies and Projects views get their own sections below. The others, briefly (pp.43-46):

  • Data Sets lists stored data sets. A version has Overview, Tables and Components tabs, and the Actions menu can reset a version to a target, delete or lock it (the plans, workflows and warehouse chapter covers this).
  • Monitor lists jobs with ID, name, status, project, times and user. Select a job and use Actions.
  • Parameters holds global parameters, usable directly in a plan or added to a project first.
  • Administrator covers default settings, sensitivity levels, connections, dictionaries, application logs and log levels, test tool integration and pass phrases.

11.8 The Expression Builder

An expression is a small formula, like a spreadsheet formula. The Expression Builder lists functions by category and columns, so you can build one without memorising names (User Guide 10.5.10, pp.46-47). You open it with the Expression button when you create an Expression-type masking rule, add pre- or post-processing to a rule, create advanced masking rules, assign rules to a column, configure an ad hoc generation rule or set advanced expressions in plans. A Validate Expression button checks your formula.

Visual reference Informatica TDM 10.5.10 User Guide, p.47, Figure "Expression Builder". What to look for: function categories on the left, an Expression box and a Join Condition box, and OK, Cancel and Validate Expression buttons.
Example from the guide, with ShopSphere names

An advanced masking rule has two variable ports holding the masked first and last names. The output port joins them with a space:

CONCAT( CONCAT( VAR1, ' ' ), VAR2 )

VAR1 would hold a masked first_name and VAR2 a masked last_name, giving a full name such as "Priya Das". The expression is the guide's; the names are ours. Function syntax is in the Informatica Transformation Language Reference, which I did not read.
