The Informatica overview and architecture chapter gave you the map: tools, services and databases. This chapter is the tour of the part you actually touch, the Test Data Manager web page. We go through the top-level screens, then the three areas where beginners spend their first week: projects (your workspace), data sources (the tables you bring in), and policies (the rules about what to protect).

The aim is not to memorise buttons. It is to know where things live, why each task exists, and what you should see afterwards, so that when you open the tool the first time nothing is a surprise. The next chapter, 12, uses everything here to run profiles.

11.1 Words to know first

View
One of the main screens of Test Data Manager, chosen from the tab bar at the top (for example Policies or Projects).
Content panel and Details panel
The two areas of most screens. The Content panel lists items (rows). The Details panel shows more about the row you selected.
Actions menu
A menu that changes with the view. Almost every task in this chapter starts with "click Actions".
Data source (in a project)
A set of source tables whose descriptions (metadata) you imported into the project. Not a copy of the rows.
Data domain
A named group of columns that mean the same kind of thing, such as "Social Security Number", recognised by column name or by value shape.
Regular expression
A short text code that describes a shape of text. [0-9]{3}-[0-9]{2}-[0-9]{4} describes "three digits, a dash, two digits, a dash, four digits".
Data pattern and metadata pattern
Two kinds of regular expression on a data domain. A data pattern describes what the values look like. A metadata pattern describes what the column name looks like.
Sensitivity level
A label you give a data domain to say how sensitive it is. An administrator defines which levels exist.
Policy pack
A ready-made policy installed with TDM, covering PII, PHI or PCI data.
Impacted Objects dialog
A warning window that lists what will break when you delete or change something that is already used.

11.3 Logging in to Test Data Manager

You reach Test Data Manager with a normal web browser. The user name and password are the same ones defined in Informatica Administrator (User Guide 10.5.10, p.48).

  1. Open the Test Data Manager address in the browser.

    The format is https://hostname:portnumber/tdm/ if Transport Layer Security (encrypted web traffic) is enabled, otherwise http://hostname:portnumber/tdm/. hostname is the host name or IP address of the machine with the TDM Server. The default port is 6643 with TLS and 6605 without. The guide's example is http://TXW1779:6643/tdm/, which has a mixed style, so read the rule rather than copying the example.

    The Login dialog box appears.

  2. Enter your user name and password.

    Choose the security domain. If the Informatica domain uses LDAP authentication, the default security domain is Native.

  3. Click Login.

    Test Data Manager opens. To leave, click Logout.

Tip

If your address works in one team and not another, ask which of the two formats (http or https) and which port your environment uses. The two defaults in the guide are only defaults.
