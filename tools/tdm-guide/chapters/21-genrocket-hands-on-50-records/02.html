21.3 What we are building, and the design decisions

The syllabus deliverable is four columns and 50 rows. Here is the target, with each column's source.

Target file layout and how each column is produced

(not in output)idautomaticEvery domain gets an id attribute. We exclude it from the file with the receiver's include setting.
FirstNamefirstNameNameGen, nameType firstNameGenRocket assigns NameGen automatically to attributes with "name" in the name.

Phone NumberphoneNumberPhoneNumberGenSequential numbers, one per row.

Four choices deserve a reason.

  1. Why a separate middleName attribute? The syllabus defines Full Name as "FirstName MiddleName LastName". For the Full Name to contain the same first and last name as the other columns, it must refer to those columns, not generate new names. So the middle name needs its own attribute too.
  2. Which generator for the middle name? From docs NameGen's documented nameType choices are firstName, lastName, maleName and femaleName. There is no "middleName" type, so I use firstName, because middle names are usually given names. That is my choice, not a documented rule. The help centre also has a FullNameGen, which generates "a full name consisting of a first, middle, and last name with an optional title and suffix" (FullNameGen). It is a valid alternative, but it creates its own first and last names inside one value, so they would not match the FirstName and LastName columns. Its title and suffix percentages also default to 100, so you would have to set them to 0.
  3. Why reference attributes instead of linked generators? The documentation shows both. The linked way builds the full name inside one attribute with three generators and no helper attributes (Linked Generators Overview, "Generate a Person's Full Name"). Our task needs separate FirstName and LastName columns as well, so we build the pieces as real attributes and reference them. The overview notes the cost of this approach: the helper attributes "would need to have the visibility Parameter set to false"; otherwise they appear in the output.
  4. Why PhoneNumberGen and not a random phone generator? PhoneNumberGen is documented, with parameters. A random alternative, RandomPhoneNumberGen, is named on its page and appears in an API example with the parameters useAreaCode and uniqueNumbers, but I had no page of its own for it, so I do not use it in the main lab.
What the docs do not say about phone format

The PhoneNumberGen page describes a sequence "100-1000, 100-1001, ..., 999-9999" and its preview screenshot shows numbers like (800) 600-1000. It does not list a format option. If your project needs 10 plain digits like ShopSphere's sample phone 9876543210, the documented route is a second linked generator such as StringRemoveGen (parameters reference, valueToRemove, removalType) or StringReplacementGen (value, fromText, toText) to strip punctuation. See the extension ideas in 21.7.

21.4 Before you start: the checklist

The lab has two halves. The design half happens in the GenRocket web platform in your browser. The run half happens on a computer with the GenRocket Runtime installed (see the overview chapter for what the Runtime is). You need both.

  • A GenRocket login with permission to create projects. If the New Project button is missing, the project page says you lack that permission and must ask the organization admin.
  • The Runtime installed and working: the command genrocket must be recognised in a terminal. The setup page for your operating system covers it, along with a supported Java version.
  • Your resource values set. From docs Each user sets the path for resource.output.directory (where output files are written) and resource.home.directory in the upper right of the Project Dashboard. The help centre recommends using different folders for output and home, and not the same path for all (resource values and your user profile).
  • Your user profile downloaded and placed in the .genrocket folder. Every time you change a resource value, download it again (Download menu, Download My Profile).
  • A text editor or spreadsheet to open the result.

If any of this is missing, ask your trainer. I did not have an account, so I could not test the install part.
