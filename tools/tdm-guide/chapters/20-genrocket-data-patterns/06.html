20.13 Recap

Recap
  • Test data needs patterns: typical data for positive tests, tricky data (boundary, edge, null) for negative tests.
  • Sequential: RangeGen (startRange, jumpAmount, waitAmount), the domain id, ListGen in order, PhoneNumberGen. A range that wraps is not unique.
  • Random: RandomGen, NameGen, ListGen and RandomStringGen; a seed makes random data repeatable, and two attributes with the same seed and settings repeat each other.
  • Weights: WeightGen for two-way splits, MultiWeightGen with exactPercentage True for exact shares.
  • Linked and conditional generators run left to right and may only reference what is to their left (and attributes above them). EvalCaseGen handles if/else; EdgeCaseGen mixes in edge values by cycle, percentage or condition.
  • Null and blank: attribute % Null and Null Value, NullGen, ConstantGen with #{BLANK} or #{EMPTY}, Output Condition, and the receiver's nullValue.
  • Boundary value analysis: test just below, on and just above each limit, plus one typical value. In GenRocket use exact lists (ListGen with setLoop True) for boundaries.
  • Enforce Type/Limit keeps values inside the column; NumberFormatGen fixes decimals; FlexibleDateRangeGen and DateDeltaGen cover dates. Verify uncertain behaviour in Preview.
