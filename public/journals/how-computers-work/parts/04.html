Logic gates and decisions

Turn Boolean rules into circuits that can genuinely select and calculate.

Six connected lessonsA diagram per chapterStart from first principles

The story before the details

A logic gate does not add values merely because its inputs look like binary digits. It implements a Boolean relationship. AND asks whether both input conditions are true. OR asks whether at least one is true. XOR detects difference. Those simple functions are enough to express much richer rules when composed.

A truth table is a complete behavioral specification for a simple gate. You list every possible input and show the desired output. It does not reveal how many transistors are used or how fast signals propagate, but it tells you precisely what must happen. Once the table is fixed, a designer can construct the function from gates.

Multiplexers turn conditional selection into physical wiring behavior. Decoders turn binary codes into one-of-many selection signals. The significance is enormous: addition circuits cannot build a useful programmable machine unless the machine can also decide which input, register, memory slot, or operation to use.
