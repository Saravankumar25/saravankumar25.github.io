Eight-bit subtraction

Set 3 of 14 · 32 worked questions. Predict your result before expanding the solution.

Bitwise arithmetic · Problem 0065

Calculate 34 − 225 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=00100010 and B=11100001.
  2. The unsigned values are A=34 and B=225.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 11100001 → 00011110.
  5. Add one to the inverted byte: 00011110 + 1 → 00011111.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 00100010 + 00011111.
  8. Keep only the lowest eight bits: 01000001.
  9. Normal integers give 34−225=-191.
  10. After modulo 256, the result is 65.
  11. The signed interpretation of the output byte is 65.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 01000001 (65 unsigned)
