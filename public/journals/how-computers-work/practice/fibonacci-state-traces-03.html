Sequential programs · Problem 0065

At Fibonacci iteration 64, what is the output and next pair of register values?

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Iteration number 64 begins with the pair of registers a=10610209857723, b=17167680177565.
  2. The current output is register a, so the emitted term is 10610209857723.
  3. Calculate a temporary sum t = a+b = 10610209857723+17167680177565 = 27777890035288.
  4. Copy the previous value of b into the new a register.
  5. The new a is 17167680177565.
  6. Copy the computed temporary t into the new b register.
  7. The new b is 27777890035288.
  8. After the update, the pair is (17167680177565, 27777890035288).
  9. On the next iteration, the machine will emit 17167680177565.
  10. The ordering matters: updating a too early without a temporary could destroy a needed operand.
  11. This trace uses unlimited mathematical integers; an eight-bit real register would wrap far earlier.

Final answer: output 10610209857723; pair (17167680177565, 27777890035288)
