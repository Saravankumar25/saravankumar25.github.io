Eight-bit subtraction

Bitwise arithmetic · Problem 0385

Calculate 232 − 235 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=11101000 and B=11101011.
  2. The unsigned values are A=232 and B=235.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 11101011 → 00010100.
  5. Add one to the inverted byte: 00010100 + 1 → 00010101.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 11101000 + 00010101.
  8. Keep only the lowest eight bits: 11111101.
  9. Normal integers give 232−235=-3.
  10. After modulo 256, the result is 253.
  11. The signed interpretation of the output byte is -3.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 11111101 (253 unsigned)
