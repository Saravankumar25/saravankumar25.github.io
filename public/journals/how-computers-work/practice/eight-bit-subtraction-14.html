Eight-bit subtraction

Set 14 of 14 · 4 worked questions. Predict your result before expanding the solution.

These worked traces are meant to build fluency through controlled variation. If several answers feel identical, try the next difficult value and look for the point where a carry, sign, branch, or selected memory address changes the outcome.

Bitwise arithmetic · Problem 0417

Calculate 253 − 126 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=11111101 and B=01111110.
  2. The unsigned values are A=253 and B=126.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 01111110 → 10000001.
  5. Add one to the inverted byte: 10000001 + 1 → 10000010.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 11111101 + 10000010.
  8. Keep only the lowest eight bits: 01111111.
  9. Normal integers give 253−126=127.
  10. After modulo 256, the result is 127.
  11. The signed interpretation of the output byte is 127.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 01111111 (127 unsigned)
