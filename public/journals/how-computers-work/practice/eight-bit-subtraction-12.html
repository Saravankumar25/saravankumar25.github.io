Eight-bit subtraction

Bitwise arithmetic · Problem 0353

Calculate 212 − 230 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=11010100 and B=11100110.
  2. The unsigned values are A=212 and B=230.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 11100110 → 00011001.
  5. Add one to the inverted byte: 00011001 + 1 → 00011010.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 11010100 + 00011010.
  8. Keep only the lowest eight bits: 11101110.
  9. Normal integers give 212−230=-18.
  10. After modulo 256, the result is 238.
  11. The signed interpretation of the output byte is -18.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 11101110 (238 unsigned)
