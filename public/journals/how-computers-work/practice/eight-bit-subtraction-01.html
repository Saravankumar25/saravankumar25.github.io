Eight-bit subtraction

Set 1 of 14 · 32 worked questions. Predict your result before expanding the solution.

Bitwise arithmetic · Problem 0001

Calculate 0 − 180 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=00000000 and B=10110100.
  2. The unsigned values are A=0 and B=180.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 10110100 → 01001011.
  5. Add one to the inverted byte: 01001011 + 1 → 01001100.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 00000000 + 01001100.
  8. Keep only the lowest eight bits: 01001100.
  9. Normal integers give 0−180=-180.
  10. After modulo 256, the result is 76.
  11. The signed interpretation of the output byte is 76.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 01001100 (76 unsigned)
