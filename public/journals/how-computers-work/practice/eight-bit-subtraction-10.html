Eight-bit subtraction

Bitwise arithmetic · Problem 0289

Calculate 172 − 166 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=10101100 and B=10100110.
  2. The unsigned values are A=172 and B=166.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 10100110 → 01011001.
  5. Add one to the inverted byte: 01011001 + 1 → 01011010.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 10101100 + 01011010.
  8. Keep only the lowest eight bits: 00000110.
  9. Normal integers give 172−166=6.
  10. After modulo 256, the result is 6.
  11. The signed interpretation of the output byte is 6.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 00000110 (6 unsigned)
