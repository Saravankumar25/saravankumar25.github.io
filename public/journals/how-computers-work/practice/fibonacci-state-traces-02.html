Sequential programs · Problem 0033

At Fibonacci iteration 32, what is the output and next pair of register values?

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Iteration number 32 begins with the pair of registers a=2178309, b=3524578.
  2. The current output is register a, so the emitted term is 2178309.
  3. Calculate a temporary sum t = a+b = 2178309+3524578 = 5702887.
  4. Copy the previous value of b into the new a register.
  5. The new a is 3524578.
  6. Copy the computed temporary t into the new b register.
  7. The new b is 5702887.
  8. After the update, the pair is (3524578, 5702887).
  9. On the next iteration, the machine will emit 3524578.
  10. The ordering matters: updating a too early without a temporary could destroy a needed operand.
  11. This trace uses unlimited mathematical integers; an eight-bit real register would wrap far earlier.

Final answer: output 2178309; pair (3524578, 5702887)
