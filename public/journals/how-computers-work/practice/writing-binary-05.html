Foundations · Problem 0129

Express decimal 448 in 10-bit unsigned binary.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. The target is the ordinary decimal value 448.
  2. Choose the smallest practical fixed width: 10 bits can hold the target.
  3. The highest available weight at that width is 512.
  4. Weight 512: skip it because remaining 448 is below 512; write bit 0; new remainder 448.
  5. Weight 256: take it because remaining 448 is at least 256; write bit 1; new remainder 192.
  6. Weight 128: take it because remaining 192 is at least 128; write bit 1; new remainder 64.
  7. Weight 64: take it because remaining 64 is at least 64; write bit 1; new remainder 0.
  8. Weight 32: skip it because remaining 0 is below 32; write bit 0; new remainder 0.
  9. Weight 16: skip it because remaining 0 is below 16; write bit 0; new remainder 0.
  10. Weight 8: skip it because remaining 0 is below 8; write bit 0; new remainder 0.
  11. Weight 4: skip it because remaining 0 is below 4; write bit 0; new remainder 0.
  12. Weight 2: skip it because remaining 0 is below 2; write bit 0; new remainder 0.
  13. Weight 1: skip it because remaining 0 is below 1; write bit 0; new remainder 0.
  14. Continue until the ones column; the final remainder must be zero.
  15. Reading the recorded bits left to right gives 0111000000.
  16. Confirm the bit weights sum back to 448.
  17. Answer: 448₁₀ = 0111000000₂.

Final answer: 0111000000
