Fibonacci state traces

Set 1 of 3 · 32 worked questions. Predict your result before expanding the solution.

These worked traces are meant to build fluency through controlled variation. If several answers feel identical, try the next difficult value and look for the point where a carry, sign, branch, or selected memory address changes the outcome.

Sequential programs · Problem 0001

At Fibonacci iteration 0, what is the output and next pair of register values?

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Iteration number 0 begins with the pair of registers a=0, b=1.
  2. The current output is register a, so the emitted term is 0.
  3. Calculate a temporary sum t = a+b = 0+1 = 1.
  4. Copy the previous value of b into the new a register.
  5. The new a is 1.
  6. Copy the computed temporary t into the new b register.
  7. The new b is 1.
  8. After the update, the pair is (1, 1).
  9. On the next iteration, the machine will emit 1.
  10. The ordering matters: updating a too early without a temporary could destroy a needed operand.
  11. This trace uses unlimited mathematical integers; an eight-bit real register would wrap far earlier.

Final answer: output 0; pair (1, 1)
