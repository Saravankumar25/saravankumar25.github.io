The story before the details

A CPU is not an ALU with a fancy name. It is a coordinated system containing storage, arithmetic, data paths and sequencing. For a simple accumulator CPU, the accumulator stores a working value, memory stores additional values, an instruction register holds the currently selected command and a program counter tracks where execution goes next.

Every instruction therefore requires both data movement and control. To add a value from memory, hardware must select a memory address, make the memory data available, route it to the ALU, perform addition, and capture the result into a register. The sequence is straightforward once the individual parts are familiar.

The fetch-decode-execute cycle is a practical mental model, not a literal universal implementation sequence. Modern processors pipeline stages and perform multiple operations in flight. First, learn the tiny working model with complete confidence; then the optimization strategies will have something concrete to extend.
