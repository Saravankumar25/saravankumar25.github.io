Eight-bit subtraction

Bitwise arithmetic · Problem 0161

Calculate 94 − 81 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=01011110 and B=01010001.
  2. The unsigned values are A=94 and B=81.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 01010001 → 10101110.
  5. Add one to the inverted byte: 10101110 + 1 → 10101111.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 01011110 + 10101111.
  8. Keep only the lowest eight bits: 00001101.
  9. Normal integers give 94−81=13.
  10. After modulo 256, the result is 13.
  11. The signed interpretation of the output byte is 13.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 00001101 (13 unsigned)
