Signed eight-bit values

Set 6 of 8 · 32 worked questions. Predict your result before expanding the solution.

These worked traces are meant to build fluency through controlled variation. If several answers feel identical, try the next difficult value and look for the point where a carry, sign, branch, or selected memory address changes the outcome.

Foundations · Problem 0161

Interpret 10100000 as an 8-bit two’s complement value.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Treat 10100000 as exactly eight bits.
  2. For signed 8-bit values the leftmost column has weight −128, not +128.
  3. The remaining seven columns have weights 64, 32, 16, 8, 4, 2 and 1.
  4. The leading sign bit is 1, so its signed contribution is -128.
  5. The lower seven bits contribute 32.
  6. Add those contributions: -128 + 32 = -96.
  7. As an unsigned pattern, the same eight bits represent 160.
  8. The signed range for eight bits is −128 through +127.
  9. Bitwise inversion alone yields 01011111; inversion plus one wraps modulo 256.
  10. The eight-bit negated pattern is 01100000.
  11. Answer: signed(10100000) = -96.

Final answer: -96
