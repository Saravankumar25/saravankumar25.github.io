Express decimal 512 in 10-bit unsigned binary.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. The target is the ordinary decimal value 512.
  2. Choose the smallest practical fixed width: 10 bits can hold the target.
  3. The highest available weight at that width is 512.
  4. Weight 512: take it because remaining 512 is at least 512; write bit 1; new remainder 0.
  5. Weight 256: skip it because remaining 0 is below 256; write bit 0; new remainder 0.
