Branch and loop tracing

Set 3 of 4 · 32 worked questions. Predict your result before expanding the solution.

These worked traces are meant to build fluency through controlled variation. If several answers feel identical, try the next difficult value and look for the point where a carry, sign, branch, or selected memory address changes the outcome.

Program execution · Problem 0065

Start a counter at 196; subtract 3 each iteration while it remains >0. How many iterations?

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. The program starts with an accumulator/counter containing 196.
  2. One loop iteration subtracts 3 from the counter.
  3. A conditional branch repeats the body only while the counter is greater than zero.
  4. After one iteration the counter is 193.
  5. After two iterations the counter is 190.
  6. In general, after k iterations the counter is 196 − 3×k.
  7. The loop first stops when k≥196/3.
  8. The smallest whole-number iteration count meeting that requirement is 66.
  9. The final counter equals 196−66×3=-2.
  10. The next PC must take the fall-through route instead of the repeat branch.
  11. This example uses a greater-than-zero condition; branch-on-not-equal would have different termination behavior for some step sizes.

Final answer: 66 iterations

Start a counter at 86; subtract 3 each iteration while it remains >0. How many iterations?

Reveal detailed solution →
  1. The program starts with an accumulator/counter containing 86.
  2. One loop iteration subtracts 3 from the counter.
  3. A conditional branch repeats the body only while the counter is greater than zero.
  4. After one iteration the counter is 83.
  5. After two iterations the counter is 80.
  6. In general, after k iterations the counter is 86 − 3×k.
  7. The loop first stops when k≥86/3.
  8. The smallest whole-number iteration count meeting that requirement is 29.
  9. The final counter equals 86−29×3=-1.
  10. The next PC must take the fall-through route instead of the repeat branch.
  11. This example uses a greater-than-zero condition; branch-on-not-equal would have different termination behavior for some step sizes.
