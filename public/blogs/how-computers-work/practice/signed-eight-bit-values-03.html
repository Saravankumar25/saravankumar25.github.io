Signed eight-bit values

Set 3 of 8 · 32 worked questions. Predict your result before expanding the solution.

These worked traces are meant to build fluency through controlled variation. If several answers feel identical, try the next difficult value and look for the point where a carry, sign, branch, or selected memory address changes the outcome.

Foundations · Problem 0065

Interpret 01000000 as an 8-bit two’s complement value.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Treat 01000000 as exactly eight bits.
  2. For signed 8-bit values the leftmost column has weight −128, not +128.
  3. The remaining seven columns have weights 64, 32, 16, 8, 4, 2 and 1.
  4. The leading sign bit is 0, so its signed contribution is 0.
  5. The lower seven bits contribute 64.
  6. Add those contributions: 0 + 64 = 64.
  7. As an unsigned pattern, the same eight bits represent 64.
  8. The signed range for eight bits is −128 through +127.
  9. Bitwise inversion alone yields 10111111; inversion plus one wraps modulo 256.
  10. The eight-bit negated pattern is 11000000.
  11. Answer: signed(01000000) = 64.

Final answer: 64

  2. For signed 8-bit values the leftmost column has weight −128, not +128.
  3. The remaining seven columns have weights 64, 32, 16, 8, 4, 2 and 1.
  4. The leading sign bit is 0, so its signed contribution is 0.
  5. The lower seven bits contribute 95.
  6. Add those contributions: 0 + 95 = 95.
  7. As an unsigned pattern, the same eight bits represent 95.
  8. The signed range for eight bits is −128 through +127.
  9. Bitwise inversion alone yields 10100000; inversion plus one wraps modulo 256.
  10. The eight-bit negated pattern is 10100001.
  11. Answer: signed(01011111) = 95.

Final answer: 95
