Eight-bit subtraction

Set 4 of 14 · 32 worked questions. Predict your result before expanding the solution.

Bitwise arithmetic · Problem 0097

Calculate 57 − 182 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=00111001 and B=10110110.
  2. The unsigned values are A=57 and B=182.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 10110110 → 01001001.
  5. Add one to the inverted byte: 01001001 + 1 → 01001010.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 00111001 + 01001010.
  8. Keep only the lowest eight bits: 10000011.
  9. Normal integers give 57−182=-125.
  10. After modulo 256, the result is 131.
  11. The signed interpretation of the output byte is -125.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 10000011 (131 unsigned)
