RAM addressing

Set 2 of 6 · 32 worked questions. Predict your result before expanding the solution.

These worked traces are meant to build fluency through controlled variation. If several answers feel identical, try the next difficult value and look for the point where a carry, sign, branch, or selected memory address changes the outcome.

State and memory · Problem 0033

RAM[3] initially stores 160. Write 179 there, then read the same location. What returns?

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. The machine models 16 byte-wide addresses: 0–15.
  2. Each location stores an eight-bit data word.
  3. At the start, RAM[3] contains 10100000 (160 unsigned).
  4. The CPU puts the four-bit address 0011 on the address lines.
  5. The decoder selects row 3, not row 8.
  6. Write-enable becomes active and the incoming data lines carry 10110011.
  7. The selected stored byte is replaced with 10110011.
  8. The write does not inherently change RAM[8].
  9. A later read of row 3 selects the new contents.
  10. The output data is 10110011, which equals 179 decimal.
  11. The address determines WHERE the information is stored; the data determines WHAT is stored.

Final answer: 179

  11. The address determines WHERE the information is stored; the data determines WHAT is stored.

State and memory · Problem 0064

RAM[12] initially stores 51. Write 46 there, then read the same location. What returns?

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. The machine models 16 byte-wide addresses: 0–15.
  2. Each location stores an eight-bit data word.
  3. At the start, RAM[12] contains 00110011 (51 unsigned).
  4. The CPU puts the four-bit address 1100 on the address lines.
  5. The decoder selects row 12, not row 1.
  6. Write-enable becomes active and the incoming data lines carry 00101110.
  7. The selected stored byte is replaced with 00101110.
  8. The write does not inherently change RAM[1].
  9. A later read of row 12 selects the new contents.
  10. The output data is 00101110, which equals 46 decimal.
  11. The address determines WHERE the information is stored; the data determines WHAT is stored.

Final answer: 46
