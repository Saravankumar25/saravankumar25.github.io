Eight-bit subtraction

Bitwise arithmetic · Problem 0257

Calculate 157 − 178 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=10011101 and B=10110010.
  2. The unsigned values are A=157 and B=178.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 10110010 → 01001101.
  5. Add one to the inverted byte: 01001101 + 1 → 01001110.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 10011101 + 01001110.
  8. Keep only the lowest eight bits: 11101011.
  9. Normal integers give 157−178=-21.
  10. After modulo 256, the result is 235.
  11. The signed interpretation of the output byte is -21.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 11101011 (235 unsigned)
