Bitwise logic

Set 9 of 9 · 14 worked questions. Predict your result before expanding the solution.

Boolean logic · Problem 0257

Calculate 11110001 XOR 00110110.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. A is the eight-bit string 11110001.
  2. B is the eight-bit string 00110110.
  3. The operation is XOR, applied separately to each matching bit position.
  4. Position 7 (weight 128): XOR(1, 0) = 1.
  5. Position 6 (weight 64): XOR(1, 0) = 1.
  6. Position 5 (weight 32): XOR(1, 1) = 0.
  7. Position 4 (weight 16): XOR(1, 1) = 0.
  8. Position 3 (weight 8): XOR(0, 0) = 0.
  9. Position 2 (weight 4): XOR(0, 1) = 1.
  10. Position 1 (weight 2): XOR(0, 1) = 1.
  11. Position 0 (weight 1): XOR(1, 0) = 1.
  12. Concatenate the output bits from position seven to zero: 11000111.
  13. The output is 199 when interpreted as unsigned decimal.
  14. No arithmetic carries occur in a bitwise XOR operation.

Final answer: 11000111
