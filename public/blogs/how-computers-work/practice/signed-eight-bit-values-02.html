Signed eight-bit values

Set 2 of 8 · 32 worked questions. Predict your result before expanding the solution.

These worked traces are meant to build fluency through controlled variation. If several answers feel identical, try the next difficult value and look for the point where a carry, sign, branch, or selected memory address changes the outcome.

Foundations · Problem 0033

Interpret 00100000 as an 8-bit two’s complement value.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Treat 00100000 as exactly eight bits.
  2. For signed 8-bit values the leftmost column has weight −128, not +128.
  3. The remaining seven columns have weights 64, 32, 16, 8, 4, 2 and 1.
  4. The leading sign bit is 0, so its signed contribution is 0.
  5. The lower seven bits contribute 32.
  6. Add those contributions: 0 + 32 = 32.
  7. As an unsigned pattern, the same eight bits represent 32.
  8. The signed range for eight bits is −128 through +127.
  9. Bitwise inversion alone yields 11011111; inversion plus one wraps modulo 256.
  10. The eight-bit negated pattern is 11100000.
  11. Answer: signed(00100000) = 32.

Final answer: 32

  2. For signed 8-bit values the leftmost column has weight −128, not +128.
  3. The remaining seven columns have weights 64, 32, 16, 8, 4, 2 and 1.
  4. The leading sign bit is 0, so its signed contribution is 0.
  5. The lower seven bits contribute 63.
  6. Add those contributions: 0 + 63 = 63.
  7. As an unsigned pattern, the same eight bits represent 63.
  8. The signed range for eight bits is −128 through +127.
  9. Bitwise inversion alone yields 11000000; inversion plus one wraps modulo 256.
  10. The eight-bit negated pattern is 11000001.
  11. Answer: signed(00111111) = 63.

Final answer: 63
