Branch and loop tracing

Set 1 of 4 · 32 worked questions. Predict your result before expanding the solution.

These worked traces are meant to build fluency through controlled variation. If several answers feel identical, try the next difficult value and look for the point where a carry, sign, branch, or selected memory address changes the outcome.

Program execution · Problem 0001

Start a counter at 4; subtract 2 each iteration while it remains >0. How many iterations?

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. The program starts with an accumulator/counter containing 4.
  2. One loop iteration subtracts 2 from the counter.
  3. A conditional branch repeats the body only while the counter is greater than zero.
  4. After one iteration the counter is 2.
  5. After two iterations the counter is 0.
  6. In general, after k iterations the counter is 4 − 2×k.
  7. The loop first stops when k≥4/2.
  8. The smallest whole-number iteration count meeting that requirement is 2.
  9. The final counter equals 4−2×2=0.
  10. The next PC must take the fall-through route instead of the repeat branch.
  11. This example uses a greater-than-zero condition; branch-on-not-equal would have different termination behavior for some step sizes.

Final answer: 2 iterations

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. The program starts with an accumulator/counter containing 94.
  2. One loop iteration subtracts 2 from the counter.
  3. A conditional branch repeats the body only while the counter is greater than zero.
  4. After one iteration the counter is 92.
  5. After two iterations the counter is 90.
  6. In general, after k iterations the counter is 94 − 2×k.
  7. The loop first stops when k≥94/2.
  8. The smallest whole-number iteration count meeting that requirement is 47.
  9. The final counter equals 94−47×2=0.
  10. The next PC must take the fall-through route instead of the repeat branch.
  11. This example uses a greater-than-zero condition; branch-on-not-equal would have different termination behavior for some step sizes.

Final answer: 47 iterations
