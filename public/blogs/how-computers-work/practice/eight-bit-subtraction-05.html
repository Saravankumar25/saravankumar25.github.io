Eight-bit subtraction

Bitwise arithmetic · Problem 0129

Calculate 79 − 38 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=01001111 and B=00100110.
  2. The unsigned values are A=79 and B=38.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 00100110 → 11011001.
  5. Add one to the inverted byte: 11011001 + 1 → 11011010.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 01001111 + 11011010.
  8. Keep only the lowest eight bits: 00101001.
  9. Normal integers give 79−38=41.
  10. After modulo 256, the result is 41.
  11. The signed interpretation of the output byte is 41.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 00101001 (41 unsigned)
