Eight-bit subtraction

Bitwise arithmetic · Problem 0193

Calculate 118 − 69 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=01110110 and B=01000101.
  2. The unsigned values are A=118 and B=69.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 01000101 → 10111010.
  5. Add one to the inverted byte: 10111010 + 1 → 10111011.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 01110110 + 10111011.
  8. Keep only the lowest eight bits: 00110001.
  9. Normal integers give 118−69=49.
  10. After modulo 256, the result is 49.
  11. The signed interpretation of the output byte is 49.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 00110001 (49 unsigned)
