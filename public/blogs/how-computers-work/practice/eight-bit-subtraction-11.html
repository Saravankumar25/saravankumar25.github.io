Eight-bit subtraction

Bitwise arithmetic · Problem 0321

Calculate 190 − 116 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=10111110 and B=01110100.
  2. The unsigned values are A=190 and B=116.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 01110100 → 10001011.
  5. Add one to the inverted byte: 10001011 + 1 → 10001100.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 10111110 + 10001100.
  8. Keep only the lowest eight bits: 01001010.
  9. Normal integers give 190−116=74.
  10. After modulo 256, the result is 74.
  11. The signed interpretation of the output byte is 74.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 01001010 (74 unsigned)
