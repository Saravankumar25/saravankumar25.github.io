Eight-bit subtraction

Bitwise arithmetic · Problem 0225

Calculate 139 − 34 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=10001011 and B=00100010.
  2. The unsigned values are A=139 and B=34.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 00100010 → 11011101.
  5. Add one to the inverted byte: 11011101 + 1 → 11011110.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 10001011 + 11011110.
  8. Keep only the lowest eight bits: 01101001.
  9. Normal integers give 139−34=105.
  10. After modulo 256, the result is 105.
  11. The signed interpretation of the output byte is 105.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 01101001 (105 unsigned)
