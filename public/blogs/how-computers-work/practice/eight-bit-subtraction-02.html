Eight-bit subtraction

Bitwise arithmetic · Problem 0033

Calculate 14 − 127 in eight-bit modular arithmetic.

Try it on paper first. The worked answer is hidden below.

Reveal detailed solution →
  1. Start with A=00001110 and B=01111111.
  2. The unsigned values are A=14 and B=127.
  3. Rewrite subtraction as A + (NOT B) + 1.
  4. Invert every bit of B: 01111111 → 10000000.
  5. Add one to the inverted byte: 10000000 + 1 → 10000001.
  6. This new byte represents the modular additive inverse of B.
  7. Add A and modular −B: 00001110 + 10000001.
  8. Keep only the lowest eight bits: 10001111.
  9. Normal integers give 14−127=-113.
  10. After modulo 256, the result is 143.
  11. The signed interpretation of the output byte is -113.
  12. Discarding the ninth carry is valid for the fixed-width modular result; signed overflow is a separate question.

Final answer: 10001111 (143 unsigned)
